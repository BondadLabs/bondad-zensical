## Inline elements

- Keys: ++ctrl+alt+del++, ++cmd+k++, ++enter++
- Marked text: ==this is highlighted==
- Inserted text: ^^this was added^^
- Deleted text: ~~this was removed~~
- Sub and superscript: H~2~O, 2^10^
- Inline code with highlighting: `#!python print("hello")`
- An abbreviation: GPU
- A footnote reference[^1]

*[GPU]: Graphics Processing Unit
