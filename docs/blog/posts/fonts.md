# Inter and JetBrains Mono

Why the theme pairs Inter for body text with JetBrains Mono for code and,
with the terminal accents on, for headings.

<!-- more -->

JetBrains Mono ExtraBold is also the face of the `> bondad_` logo, so the
headings and the logo read as the same voice.
